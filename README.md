# ShieldMod
Мод на майнкрафт, автовзятие щита в руки по голосовой активации
Однажды запарился доставать и убирать щит каждый раз руками, и я решил сделать мод, который делает это по голосовой активации на Java. Говоришь в микрофон "Щит", он берет его в руки. говоришь снова, он убирает туда же, где и взял. поскольку это чисто локальный мод, чтобы не ломать мозги я сделал разделение, запускаешь пайтон файл на фоне, который слушает голос, а сам мод работает в самой игре. когда пайтон слышит "щит" он передает сигнал твоему моду в игре, тот уже берет или убирает щит.
