Гибридная модульная система голосового управления экипировкой в игре Minecraft, связывающая асинхронный аудио-демон на Python с нативным модом на Java через локальный сетевой сокет (IPC).

### Архитектурные особенности:
* **Межпроцессное взаимодействие (IPC):** Использование легковесного локального сетевого сокета (TCP/Socket) для мгновенной передачи сигналов между Python-бэкендом и игровым клиентом на Java.
* **Асинхронное распознавание речи:** Фоновый сервис непрерывного прослушивания микрофона, анализирующий голосовые триггеры с минимальной задержкой.
* **Автоматическое управление инвентарем:** Логика умного переключения: повторная голосовая команда автоматически возвращает щит ровно в тот слот инвентаря, откуда он был взят.
* **Двуязычная архитектура:** Полная изоляция тяжелой аудио-обработки в Python для предотвращения просадок FPS внутри движка Minecraft на Java.

### Стек технологий:
* Python 3.12 (Служба распознавания речи и сокет-сервер)
* Java 17+ (Minecraft Mod / Forge / Fabric API)
* SpeechRecognition / PyAudio (Захват аудиопотока)
* TCP/IP Local Sockets (Межпроцессная связь)
